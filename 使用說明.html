TRAVEL BOOK · GUIDE

填表就能使用

解壓縮整份模板，保留檔案的位置，再用 Chrome 或 Edge 開啟 index.html。不需要安裝工具、編譯或修改程式。請使用一般瀏覽視窗，讓旅程能持續保存。

開始一趟旅程

  1. 按「建立旅程」，填入名稱、日期與旅伴；也可按「複製旅程」沿用目前的行程、預約與檢查表。副本不會帶入留言、待購、備註與勾選。
  2. 按每日卡片的「編輯行程」，加入活動、時間、交通與費用、參考連結及路線站點。座標可以留白；地點名稱仍能用於 Google Maps 導航。
  3. 在「編輯旅程設定」管理總覽卡片、預約、檢查表與留言分類。修改日期會依目前卡片順序移動日期；縮短旅程會刪掉尾端卡片。預約摘要的日期請自行調整。
  4. 可以交換未鎖定的行程日期，固定交通與預約日可勾選鎖定。
  5. 用頁首的旅程選單切換不同旅程，各趟資料分開保存。可保存最多 40 趟，每趟最多 60 天。

備份、換裝置與交給旅伴

按檢查表區的「匯出完整旅程」，保存下載的 JSON 檔。它包含行程設定、當前日期安排、勾選、備註、待購、留言與動態。其他人用「匯入旅程／模板」選取這個檔案，就會建立一份獨立旅程，不覆蓋既有內容。檔案上限 5 MB；不能用舊版僅含進度的檔案取代完整旅程檔。

資料只保存在目前瀏覽器。旅伴之間沒有即時同步，也不會自動合併兩份修改；交換前請約定由誰維護最新版本。清除瀏覽器資料、換瀏覽器或搬動本機檔案，可能看不到原本旅程，請先匯出備份再匯入。列印會包含全部日期，即使畫面目前只顯示單日。

製作可重用模板

按「匯出可重用模板」會保留目前排列的行程、總覽、預約、檢查表與連結，將旅伴改為通用暱稱，並清空勾選、備註、待購、留言與動態。分享前仍需檢查行程文字、住宿與連結，移除私人資訊。這個按鈕不會自動辨識文字中的訂位代碼或個人資料。

離線與地圖、天氣

本機開啟時，行程編輯與備份功能可離線使用。本機檔案模式只顯示站點與手動導航連結；以 HTTP(S) 開啟時，地圖才會在使用者開啟後下载底圖。天氣預設關閉，若在設定啟用，將城市座標與時區送到 Open-Meteo，僅顯示預報範圍內的日期。Open-Meteo 免費 API 限非商業用途，商業部署請保持天氣關閉或選擇合適服務。已上架的 HTTPS 網站可加入手機主畫面；首次連線載入後，手冊可離線開啟。
