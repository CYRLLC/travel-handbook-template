# Changelog

## 1.0.0 - 2026-10-11

- Adopted Travel Handbook Template / 旅遊手冊範本 as the generic project identity.
- Preserved local trip editing, validated import/export, mobile layouts and PWA support.
- Removed owner-specific trip identifiers from public privacy checks; optional private rules remain outside Git.
- Added pinned development dependencies, reproducible npm scripts and cross-platform browser tests.
- Added CI validation and a build-only ZIP artifact with no automatic deployment.
- Added contribution guidance, community rules, issue/PR templates and third-party notices.
- Added weather provider/data attribution and documented external service conditions.
- Disabled public map tile requests in file:// mode.
- Published from a clean source snapshot using a GitHub noreply commit identity; original history stays private.
