# Community Guidelines

- Be respectful and focus feedback on the work.
- Do not harass contributors, publish private information, or share credentials and personal trip files.
- Use clear, reproducible examples and assume good intent.
- Follow the private security reporting guidance in SECURITY.md for vulnerabilities.

Maintainers may remove content that exposes private information or violates these guidelines. If you need to report conduct privately, first ask a maintainer for a private channel without posting sensitive details publicly.
